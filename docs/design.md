# 디자인 핸드오프 — 아카이브 기반 만화 뷰어

> Claude Design에 이 문서 전체를 붙여넣고 "이 명세로 UI를 디자인해줘"로 시작하세요.

---

## 제품 한 줄 요약
로컬 스토리지에 ZIP·폴더·PDF로 쌓인 수천 개 규모의 만화 컬렉션을, 압축 해제 없이 브라우저에서 열람하는 개인용 웹 리더.

## 사용자와 환경
- 사용자: 컬렉션 소유자 본인 (단독, 파워유저)
- 주 환경: 데스크톱 브라우저 (1440px 이상), 부 환경: 태블릿·모바일
- 사용 맥락: 밤에 어두운 방에서 장시간 읽기. 뷰어는 다크 기본
- 컬렉션 성격: 시리즈 수천 개, 총 수 TB. 파일명이 사실상 유일한 메타데이터

## 핵심 디자인 원칙
1. **커버와 텍스트를 대등하게** — 파일명에 `1~23(완)` 같은 정보가 들어있어 리스트 뷰가 그리드만큼 중요합니다. 리스트를 부차적 옵션으로 다루지 말 것
2. **뷰어는 크롬을 지운다** — 읽는 동안 UI가 보이지 않는 것이 기본 상태
3. **비어 있는 상태가 흔하다** — 썸네일 생성 전, 커버 실패, 손상 아카이브가 상시 존재. 이 상태들이 초라해 보이지 않아야 함
4. **밀도 높게** — 컬렉션 탐색이 주 작업. 여백보다 한 화면에 들어오는 항목 수가 중요

## 정보 구조
```
루트 (사용자가 등록한 폴더, N개)
 └─ 시리즈  — 루트의 직계 자식 하나 (폴더 / ZIP / PDF)
     └─ 권   — ZIP · 이미지 폴더 · PDF
         └─ 페이지 — 이미지 한 장
```
시리즈가 관리·표시의 기본 단위입니다.

## 화면 1 — 홈 / 라이브러리 (최우선)

**레이아웃**: 좌측 고정 사이드바 + 본문

**사이드바**
- 루트 목록 (사용자 지정 이름, 시리즈 개수 배지)
- 이어보기 / 최근 추가 / 완독
- 하단: 설정, 스캔 상태 인디케이터

**상단 바**
- 검색 입력 (초성 검색 지원)
- 정렬 선택: 이름 · 수정일 · 최근 읽은 순 · 용량 · 권 수
- 그리드 / 리스트 토글
- 스캔 진행 중일 때 진행률 표시

**본문 상단 — 이어보기**
- 진행 중인 권 카드 가로 배열. 커버 + 시리즈명 + `12 / 180p` + 진행 바
- 진행 중인 항목이 없으면 영역 자체를 숨김

**본문 — 그리드 모드**
- 반응형 커버 그리드. 커버 비율 약 2:3
- 카드 정보: 시리즈명(2줄 말줄임), 권 수, 하단 진행 바
- 호버 시: 읽기 시작 / 이어 읽기 액션 노출

**본문 — 리스트 모드**
- 컬럼: 썸네일(소형) · 시리즈명 · 형식 배지(ZIP/폴더/PDF) · 권 수 · 총 용량 · 수정일 · 진행률
- 행 밀도 높게. 정렬 가능한 헤더

**필요한 상태**
- 로딩: 스켈레톤 (레이아웃 이동 없이)
- 썸네일 미생성: 시리즈명 텍스트가 들어간 대체 커버
- 검색 결과 없음
- 루트 미등록 (최초 실행): 루트 추가로 유도하는 온보딩

---

## 화면 2 — 시리즈 상세

- 헤더: 대표 커버(대형), 시리즈명, 원본 경로(보조 텍스트), 총 권 수, 총 용량, 전체 진행률
- 액션: `처음부터 읽기` / `이어 읽기` / `이 시리즈 재스캔`
- 본문: 권 목록. 권별 썸네일 + 권 이름 + 형식 배지 + 페이지 수 + 진행 바
- 권 목록도 그리드 / 리스트 전환 가능
- 오류 상태: 열 수 없는 권(암호화·손상)은 배지로 구분하고 사유 표시

---

## 화면 3 — 뷰어 (핵심 화면)

**기본 상태**: 전체화면, UI 없음, 배경 순수 검정에 가깝게. 이미지에만 집중

**마우스 이동 또는 탭 시 오버레이 등장** (수 초 후 자동 소멸)

*상단 오버레이*
- 뒤로가기
- 시리즈명 · 권명
- 컨트롤: 표시 모드(단면 / 양면 / 세로 스크롤), 읽기 방향(좌→우 / 우→좌), 맞춤(너비 / 높이 / 원본 / 화면)

*하단 오버레이*
- 페이지 슬라이더 (드래그 시 해당 위치 썸네일 프리뷰)
- `현재 / 전체` 페이지 표시
- 썸네일 패널 토글

**썸네일 패널**: 하단 스트립 또는 전체 그리드 오버레이. 현재 페이지 강조

**필요한 상태**
- 페이지 로딩 중 (이전 페이지 유지 + 미세한 인디케이터. 흰 화면 금지)
- 권 마지막 페이지 → 다음 권으로 이동 유도 카드
- 이미지 로드 실패

**모바일**: 좌/우 탭 영역 페이지 이동, 스와이프, 중앙 탭으로 오버레이 토글

---

## 화면 4 — 설정

- 루트 관리: 목록, 추가/제거, 루트별 수동 재스캔
- 캐시: 사용량 표시, 전체 삭제
- 읽기 기본값: 읽기 방향, 표시 모드, 프리페치 페이지 수
- 테마: 라이트 / 다크 / 시스템
- 스캔 로그 열람

## 컴포넌트 인벤토리
시리즈 카드(그리드) · 시리즈 행(리스트) · 이어보기 카드 · 권 항목 · 진행 바 · 형식 배지 · 대체 커버 · 사이드바 항목 · 정렬 드롭다운 · 뷰 토글 · 스캔 인디케이터 · 뷰어 오버레이 바 · 페이지 슬라이더 · 썸네일 스트립 · 커맨드 팔레트 · 빈 상태 · 스켈레톤

## 커맨드 팔레트
`Ctrl/Cmd + K`. 시리즈명 즉시 검색 후 이동. 최근 항목 우선 표시.

## 키보드 단축키 (뷰어)
`←` `→` 페이지 · `Space` 다음 · `F` 전체화면 · `Esc` 나가기 · `T` 썸네일 패널

## 반응형 기준
- 1440px 이상: 사이드바 고정, 그리드 6~8열
- 1024~1440px: 사이드바 고정, 그리드 4~5열
- 768~1024px: 사이드바 접힘, 그리드 3열
- 768px 미만: 사이드바 드로어, 그리드 2열, 뷰어는 터치 우선

## 기술 제약
- React 18 + TypeScript + Vite + Tailwind CSS
- Go 바이너리에 정적 자원으로 내장되므로 외부 CDN 의존 없이 번들에 포함될 것
- 다크 모드는 부가 기능이 아니라 뷰어의 기본값

## 작업 우선순위
1. 홈 / 라이브러리 (그리드 + 리스트 두 모드 모두)
2. 뷰어 (기본 상태 + 오버레이 + 썸네일 패널)
3. 시리즈 상세
4. 설정, 커맨드 팔레트, 빈 상태 모음
