# F-1 정정 — 픽셀 기준 개수, 서체 라이선스 고지

이전 기록의 나머지 내용(원인·고정·검사·남은 것)은 그대로 유효하다. 아래 두 가지만 바꾼다. 바꾼 이유는 독립 검증 ISSUES(ab43bfa, 2026-11-09T08:10 verifier-1)다.

## 1. 픽셀 기준 개수 (이전 기록의 결론·"픽셀 기준 갱신" 절 정정)

- 틀린 기술: "82장 = 화살표 81장 + e45 4장". 커밋 ab43bfa 메시지의 "화살표 81장"도 같은 오류다(커밋은 재작성하지 않는다).
- 맞는 개수: manifest 해시 변경 **82장 = 화살표 78장 + e45-viewer-stale-progress 4장**. 썸네일 JPEG 변경 **77개 = 화살표 73개 + e45 4개**. 나머지 5장은 축소 뒤 같다(11c desktop·laptop·tablet, 2 size-desc desktop·laptop).
- 확인(실행): `git show 905d02a|ab43bfa:docs/pixel-baseline/synthetic/manifest.json`의 `shots` 115건 비교 → 변경 82, 그중 이름에 e45 4. `git diff --name-only 905d02a ab43bfa -- docs/pixel-baseline`의 JPEG 77, 그중 e45 4.
- 기준 이미지와 코드는 바꾸지 않았다.

## 2. 서체 라이선스 고지 (새로 추가)

- `web/src/assets/fonts/NOTICE.txt`: 서체별 원본 이름, 저작권 문구(각 woff2의 name ID 0 인용), 라이선스, 출처, 적용 파일. 대상은 이 디렉터리의 woff2 12개 전부(Gowun Batang, Noto Serif CJK TC, Noto Serif CJK KR, Noto Sans CJK JP, Archivo).
- `web/src/assets/fonts/OFL-1.1.txt`: SIL OFL 1.1 원문.
- 기존 서체도 고지가 없던 선행 누락이었다. 이번에 함께 넣었다.
- 출처·라이선스 확인 근거(2026-11-09):
  - Noto CJK 3종: `/usr/share/doc/fonts-noto-cjk/copyright`(License: SIL-1.1), 원본 저장소 notofonts/noto-cjk의 `Serif/LICENSE`·`Sans/LICENSE`(OFL 1.1).
  - Gowun Batang: 파일 name 테이블에 라이선스 항목(ID 13·14)이 없다. 저작권 문구가 가리키는 원본 저장소 yangheeryu/Gowun-Batang의 `OFL.txt`(GitHub API `license` spdx_id OFL-1.1)로 확인했다. 받은 파일 자체의 배포 묶음은 저장소에 남아 있지 않다(decisions.md E-46 §4는 "사용자가 지정한 저장소"라고만 적는다).
  - Archivo: name ID 14 `http://scripts.sil.org/OFL`, `@fontsource/archivo` 5.2.6의 LICENSE·metadata.json(OFL-1.1), 원본 저장소 Omnibus-Type/Archivo `OFL.txt`. 벤더 파일 2개가 패키지의 `archivo-latin-{400,700}-normal.woff2`와 바이트 동일함을 `cmp`로 확인했다.
- 범위 밖: 바이너리에 고지 파일을 싣는 것(크기). 고지 파일은 Vite가 import하지 않으므로 빌드 산출물에 들어가지 않는다.
