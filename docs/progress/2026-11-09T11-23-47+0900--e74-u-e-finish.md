# E-74 U-E — 가짜 uni-auth 합성 e2e, 최종 게이트, 크기 재측정

## 결론

- `make e2e-synthetic-oidc`(`scripts/e2e-oidc.sh`)가 실제 바이너리를 `auth.mode: oidc`로 띄우고, 가짜 uni-auth(`scripts/fakeoidc`, 별도 main — dist/shelf에 링크되지 않는다)를 루프백 http 예외(E-74 §2.19)로 붙여 (a)~(h)를 검사한다. 제품 코드는 바뀌지 않았다.
- 기존 `make e2e-synthetic`은 그대로다. `web/playwright.config.ts`는 `14-oidc.spec.ts`를 무시하고, `web/playwright.oidc.config.ts`만 그 spec을 데스크톱 한 뷰포트로 돈다.
- 릴리스 크기(go1.26.9, `make release SIZE_BUDGET=0`): 기본 **33 677 474 B**, avif 35 254 537 B, nopdf 23 117 986 B. 예산 33 554 432 B를 **123 042 B** 넘는다. 예산 결정은 사용자 대기 중이라 `SIZE_BUDGET`은 그대로 두고 `MEASURED_*`·README·Makefile 표만 고쳤다.

## 검사 방법

| 기준 | 어디서 | 무엇을 본다 |
| --- | --- | --- |
| (a) 복귀·쿠키 | spec (a) | 세션 없이 `/series/<sid>?from=e2e` → 서버 로그인 화면(401) → 가짜 로그인 → 같은 경로·쿼리로 복귀. 첫 진입 authorize에 `prompt` 없음. `__Host-shelf_sid`: `Path=/`, 호스트 전용, `HttpOnly`, `Secure`, `SameSite=Lax`, 값 43자 base64url, 만료 ≈ 30일. `__Host-shelf_login`은 지워짐. `/api/auth/status`의 `user.is_admin` |
| (b) 진행률 분리·표지 공유 | spec (b) | alice가 뷰어로 3쪽 저장 → bob은 `progress: null`, 이어보기 빈 목록, 표지·`cover_cv`는 alice와 같음. bob이 1쪽을 써도 alice는 3쪽 |
| (c) 허용 목록 밖 | spec (c) | mallory 콜백 403, 안내 문구와 `<code>`의 sub, 세션 쿠키 없음 |
| (d) 관리자 컨트롤·admin_only | spec (d) | alice/bob 대조: 시리즈 재스캔, 스캔 로그, 캐시 전체 삭제, 루트 재스캔 버튼 수, 계정 패널의 `관리자`, `Root.path` 공란. bob의 `POST /api/scan`·`POST …/rescan`·`DELETE /api/cache`·`GET /api/scan/log` → `403 admin_only` |
| (e) 재인증 | spec (e) | 첫 로그인 직후 재스캔 403 → `다시 로그인` 대화상자 → `prompt=login`으로 가짜 로그인 화면 → 같은 경로 복귀. `reauth_at`을 14분 전으로 → 통과, 16분 전으로 → `403 reauth_required`와 대화상자 |
| (f) 만료·이유 없는 401 | spec (f) | `expires_at`을 과거로 → 시리즈 클릭 → `prompt=none` 한 번으로 로그인 화면 없이 클릭한 경로에 도착, 세션 ID 회전, 옛 행 없음. 다른 탭 로그아웃(204) 뒤 클릭 → `/`의 서버 로그인 화면, 가짜 공급자에 요청 없음 |
| (g) 로그아웃 두 폼 | spec (g) | 계정 패널 `로그아웃` → 완료 문구, 세션 끝, 쿠키 600초 이하 → 완료 화면의 `모든 서비스에서 로그아웃` → 가짜 end_session에 `id_token_hint`(alice), 쿠키 삭제, 가짜의 세션도 끝(다시 로그인하면 로그인 화면). SPA의 `모든 서비스에서 로그아웃`(bob)도 같다 |
| (h) cross_origin | e2e-oidc.sh 4단계(curl) | 다른 Origin·이웃 포트 Origin·`Sec-Fetch-Site: cross-site`·둘 다 없음 → `403 cross_origin`(scan, settings, end-session). 같은 Origin은 세션 없음 401 — 위 403이 출처 검사라는 대조 |

- 시간 이동: 15분·12시간 경과는 `auth.db`의 세션 행(`reauth_at`, `expires_at`)을 python sqlite3로 고쳐 만든다. 서버는 매 요청 행을 읽으므로(E-74 §2.7) 판정 경로는 그대로다. sleep 없음.
- Playwright의 `page.request`는 http 출처에 `Secure` 쿠키를 보내지 않아 API 호출은 `page.evaluate`의 `fetch`로 한다(브라우저가 쿠키와 `Origin`을 붙인다). CSP 때문에 `waitForFunction`은 쓰지 않는다.
- 서버 로그에 `code`·`code_verifier`·토큰이 없는지 라운드 끝에 확인한다.
